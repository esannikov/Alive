## Як працює пілот

На час підключення учасників репозиторій тимчасово відкрито для читання; поточну видимість показує GitHub. Публічне читання не надає права запису. Для підключення учасник передає свій GitHub-логін адміністратору репозиторію. [Поточний порядок доступу й перегляду](CONTRIBUTING.md).

`main` містить спільну базову версію. Кожне завдання виконується в окремій гілці й передається на перегляд через pull request. Перед редактурою агент готує робочу гілку. Після приймання правки читачі на main із увімкненою автоматикою отримують оновлення; автор повертається до main за допомогою свого агента. Людське творче погодження записується явно.

Це окремий репозиторій, його можна відкрити як сховище Obsidian. Поточний набір містить PDF роману й текстову біблію: готові графічні концепти, медіа та розкадровки цим імпортом не додані. Особистий SuperVault не потрібний для читання й редагування пакета. Зворотна синхронізація з початковими локальними документами не налаштована; правки пілота спочатку приймаємо тут.

Перевірка: `python3 scripts/validate.py`. [Реєстр джерел](Sources/source_manifest.json) фіксує актуальні контрольні суми; [перевірка PDF](_meta/PDF_Verification.md) описує перенесення посилань.
