# Оформлення ALIVE в Obsidian

Файл `alive-editorial.css` — локальне оформлення читання: кольорові заголовки, спокійні таблиці, виразні блоки й підтримка світлого та темного режимів. Скриптів, зовнішніх шрифтів і мережевих запитів у ньому немає.

1. Скопіюйте [alive-editorial.css](alive-editorial.css) у `.obsidian/snippets` саме свого сховища Alive.
2. Відкрийте **Settings → Appearance → CSS snippets**.
3. Натисніть **Reload snippets** і ввімкніть **alive-editorial**.
4. Перевірте [головну сторінку](../README.md), [картку роботів](../Bible/Technology/Robots.md) і читабельність таблиць. Обраний користувачем світлий або темний режим зберігається.

Цей стиль оформлює також читання джерельних Markdown-файлів у Obsidian без зміни їхнього тексту. На GitHub оформлення робочих сторінок забезпечують SVG-заголовки й стандартні кольорові блоки.

Особисті налаштування `.obsidian` не передаються Git. Після оновлення CSS у репозиторії агент копіює нову версію до локального каталогу snippets. Вимкнення перемикача повертає попередній вигляд.

## Як читати акценти

- Синій **Note** у картці — опис із літературного джерела.
- Фіолетовий **Important** — висновки для концепту й відкриті рішення.
- Зелений **Tip** в інструкції — наступна практична дія.
- Жовтий **Warning** — ситуація, яка потребує уваги.

Колір завжди супроводжується текстовим поясненням. Кольоровий блок сам по собі не означає творчого затвердження.

## Підтримка стилю

Нові робочі сторінки використовують відповідний заголовок з `assets/sections`, навігацію та помірні акценти. Текст залишається Markdown. Основні файли з реєстру джерел, PDF і машинний реєстр опор зберігаються незмінними; для них оновлюється навігація й оформлення перегляду.
