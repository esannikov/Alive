# Рішення пілота

Історичний локальний журнал не перенесено. Нових творчих рішень імпорт не додає.

Після явного погодження людиною створіть окремий Markdown-файл із датою й короткою темою. Вкажіть: рішення; джерело або причину; хто й коли погодив; посилання на pull request; пов’язані сторінки й матеріали, які треба оновити. Пропозиції до погодження залишаються у своїх гілках та обговореннях.
