# Blender · моделі для сцени

282 базові коди, 303 стани й пози. Окремо до вебзбірки входить архітектурний павільйон набережної. Призначення взято з поля `target` маніфесту. Фактичне розміщення та кількість інстансів визначає модуль сцени. Для деталі наведено габарити X × Y × Z у метрах і число трикутників для кожного варіанта.
