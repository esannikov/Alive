# Хендоф для Codex · Blender-моделі для станції МОАГ

**Від:** Claude · **Дата:** 2026-11-23 · **Проєкт:** `moag-lake-district`

## Мета

Модель станції рухається до якості **невеликої комп'ютерної інді-гри**. Орієнтир — стилізований реалізм з читабельними силуетами, теплими лампами й відчуттям обжитості; не фотореалізм. Зараз більшість предметів у сцені зібрана з процедурних коробок і циліндрів. Їх треба замінити на справжні моделі, які я потім розставлю по сценах.

Поки ти моделюєш, я правлю шейдери, інтерфейс і ефекти. **Код у `source/src` не чіпай.** Твоя частина — лише файли моделей, прев'ю та маніфест.

## Технічні вимоги

| Параметр | Вимога |
|---|---|
| Формат | glTF 2.0 Binary `.glb`, без анімацій, камер і світла |
| Одиниці | **метри**, реальний розмір предмета. Масштаб сцени (1 од. = 22 м) я застосую сам |
| Осі | Y — вгору. Лицьовий бік предмета дивиться в **+Z** |
| Pivot | у центрі основи, на рівні підлоги (y = 0). Для настінних — у центрі задньої площини |
| Модифікатори | застосовані перед експортом. Weighted Normals дозволено й бажано |
| Матеріали | PBR Metallic-Roughness, **1 матеріал на предмет** (максимум 2: основний + `*_emit` для світних частин) |
| Текстури | спільний атлас для набору, 1024 px (2048 лише для героїв), JPG для кольору, PNG — тільки там, де потрібна альфа. Можна обійтися vertex color + roughness без текстур |
| Світні частини | окремий матеріал з назвою, що закінчується на `_emit` (лампи, індикатори, екрани, жар). Я підключу до них bloom |
| Розмір файлу | ≤ 400 KB на звичайний предмет, ≤ 1,2 MB на героїчний. Усе вбудовується в один HTML-файл, тож кожен мегабайт важливий |

**Бюджет трикутників (LOD0):**
- героїчні предмети, які видно зблизька — 2 000–6 000;
- меблі й обладнання — 500–2 500;
- дрібні предмети й модулі для масової розстановки — 80–600.

Загалом на весь пакет — до **150 000 унікальних трикутників**. Модулі з набору (Пакет В) я ставитиму інстансами по сотні штук, тому їх треба тримати найлегшими.

## Стиль

- Чіткі силуети, які читаються з плану палуби: виразні об'єми, а не дрібна нарізка.
- Фаска 1–2 см на всіх ребрах (Bevel + Weighted Normals), щоб краї ловили світло.
- Сліди використання в текстурі: потертості, іржа на стиках, заплатки, саморобні ремонти. На B3 діти живуть у технічних приміщеннях, і все навколо має бути пристосованим, лагодженим, саморобним.
- Палітра:
  - сталь сіро-синя `#5c6d7e`, `#3d4452`;
  - іржа `#8a5a3a`;
  - бурштинове світло ламп `#ffb35c`;
  - холодне світло Half II `#86d6ff`;
  - сигнальний жовтий `#e3b23c`;
  - тканини приглушені (вовна, джинса, клейонка `#3fa6a0`).
- Матеріали без «пластику»: шорсткість 0,5–0,85 для більшості поверхонь, метал лише там, де він справді є.

## Куди складати

```
moag-lake-district/
  blender/models/<код>_<id>.blend          ← джерела
  source/src/assets/models/<код>_<id>.glb   ← експорт
  source/src/assets/models/previews/<код>_<id>.png   ← прев'ю 512 px, 3/4 згори
  source/src/assets/models/manifest.json
```

Назва файлу: `A-01_heater.glb`, `K-12_iso_container.glb` (латиницею, без пробілів).

Формат запису в `manifest.json`:

```json
{
  "code": "A-01",
  "id": "heater",
  "file": "A-01_heater.glb",
  "title": "Обігрівач спільної кімнати",
  "tris": 3120,
  "sizeKB": 210,
  "bboxM": [0.9, 1.1, 0.5],
  "pivot": "floor-center",
  "materials": ["heater", "heater_emit"],
  "target": "Темна база · спільна кімната",
  "variants": ["default"],
  "notes": "решітка світиться"
}
```

## Порядок роботи

1. Спершу **K-01…K-07 і A-01**: швидко перевіримо весь ланцюжок експорт → вбудовування → розстановка.
2. Далі **Пакет А** у порядку таблиці.
3. Потім **Пакет В** повністю.
4. Далі **Б** і **Г**.

Після кожного пакета допиши в `manifest.json` і короткий рядок у кінець цього файлу: що готово, що ні і чому. Я заберу готові моделі й розставлю їх; сам у сцену нічого не вбудовуй.
