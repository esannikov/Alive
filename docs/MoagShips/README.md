# Моаг: внешние концепты после сверки с романом

23.10.2026. 18 вариантов; рабочие предложения, не принятый канон.

- index.html — сравнение вариантов; три проекции с выносками, шесть видов и прежний стилевой эскиз.
- source-audit.html / .md — разбор романа с физическими страницами PDF и таблицей изменений.
- *-annotated.svg — 18 листов в трёх проекциях с 14 выносками. Координаты и габариты проектные.
- *-six-views.svg — 18 листов по шесть ракурсов; та же геометрия, без реалистичной детализации.
- *-geometry.json — координаты частей, функции, габариты и результаты проверки.
- variants.json — сводка без тяжёлых массивов координат.
- previous/ — уменьшенные WebP старых стилевых изображений для сравнения. Новые формы ими не определяются.

Все парные наружные объёмы зеркальны. Проверено попадание 2016 точек условного района Ø360 × 120 м в корпус каждого варианта. Эта выборочная проверка не заменяет план помещений и конструктивный расчёт. Окна W1–W3 и ниши показаны как требования к размещению, а не готовые отверстия. Обзор, прочность, мощности, радиационная защита и теплоотвод не рассчитаны.

Использованы ALIVE.pdf и его постраничный Novel.md; расширенная World Bible сверена с романом. Источники не изменены. Размеры корабля в метрах в проверенных текстах не установлены.
