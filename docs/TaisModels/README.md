# ALIVE — Таис: пять моделей, два эпизода

[Открыть галерею](index.html) · [Промпты и происхождение кадров](generations.json) · [Оригинальные файлы](files.json)

21.10.2026. Рабочая визуальная проба, не утверждённый дизайн.

Пять исходных портретов сгенерированы с нуля через fal.ai по одному одинаковому текстовому запросу, без изображений-референсов. От каждого портрета той же моделью сделаны две независимые производные. В таблице каждая строка принадлежит одной модели: портрет → цитрусовый сад → автомат с батончиками. Все 15 первых результатов сохранены без ретуши и пересжатия.

Модели: Nano Banana 2.1; Seedream 5 Pro; GPT Image 2; GPT Image 2.5 Sunburst; FLUX.2 Max. Точные endpoint ID, request ID, параметры и ссылки на исходные файлы сохранены в JSON.

Сад основан на с. 61 романа: Зелёная магистраль, цитрусовые в кадках, возвращение с едой. Одежда этой вылазки — тёмно-синяя пайта с капюшоном, с. 52. Автомат — с. 43–44; здесь серая куртка, бриджи ниже колен и бандана. Ракурсы, свет, конкретный жест и конструкции предметов — предложения постановки. Старый шрам — пожелание к визуальному образу, не подтверждённый факт романа.

Галерея даёт сравнение конкретных попыток, а не общий рейтинг моделей. Нужно отдельно смотреть сходство внутри строки, возрастное впечатление, свет, геометрию рук/предметов и соблюдение деталей. Например, на некоторых упаковках модель самостоятельно воспроизвела бренды вопреки запросу; это результат генерации, не согласованный реквизит.

Изображения можно увеличить, переключать модели стрелками, выбирать сцены клавишами 1–3 и скачать исходный PNG. На телефоне каждая модель показана отдельной группой из трёх кадров.
