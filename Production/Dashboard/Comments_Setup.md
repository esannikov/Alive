# Комментарии World через Giscus

Состояние на 26 октября 2026: Discussions включены, репозиторий публичный. Приложение Giscus ещё не установлено, категории Comments пока нет. Код готов, но `comments.json: enabled` остаётся `false` до завершения настройки. Видимость репозитория не менялась.

## Осталось в GitHub

Войти в GitHub в браузере владельца. Установить официальное [приложение Giscus](https://github.com/apps/giscus) только для `esannikov/Alive`. В Discussions создать категорию `Comments` формата Announcement. В такой категории новые обсуждения создают сопровождающие и Giscus; это не ограничение «только бот».

После этого выполнить:

```sh
python3 scripts/check_world_comments.py
```

Команда только проверяет состояние и возвращает реальные `repoId` и `categoryId` из официального API Giscus. Не меняет доступ, не устанавливает приложение и не отправляет комментарии. После проверки формата категории в GitHub перенести значения в [comments.json](comments.json), поставить `enabled: true`, пересобрать и проверить World.

## Конфигурация

`repoId` уже проверен: `R_kgDOVCLQyQ`. ID категории не подменяется примером. Настройки: pathname, strict=1, реакции, поле ввода сверху, русский язык, тёмная тема (World всегда тёмный). Сначала откладывается сам внешний скрипт, затем iframe использует loading=lazy. В каждый main добавляется один раздел.

`/index.html` нормализуется к адресу каталога с сохранением параметров и кода изображения. Это предотвращает два обсуждения для одной страницы. Коды изображений и query-параметры не входят в ключ обсуждения. Справка и галерея имеют разные pathname и поэтому разные треды. Обсуждения первого уровня и вложенных страниц разделены строгим сопоставлением Giscus.

Новый тред появляется при первом комментарии или реакции. Тестовые комментарии не публикуются. При ошибке остаётся ссылка на обсуждения GitHub. Для чтения вход не нужен; для комментирования посетитель авторизует Giscus через GitHub. Комментарии публичны.

## Проверки

```sh
python3 scripts/build_world.py
python3 scripts/validate_world.py
python3 scripts/validate_roadmap.py
python3 scripts/validate.py
node scripts/test_world_comments.cjs
```

Браузерный тест использует локальный имитатор виджета и не отправляет внешних сообщений. Он проверяет все маршруты, строгие параметры, ленивую загрузку, алиас index.html, сохранение кода после OAuth-возврата, отсутствие двойного виджета, мобильный экран и ошибку загрузки. После установки приложения отдельно проверить настоящий iframe на опубликованных страницах персонажа, робота, корабля и обзора.
