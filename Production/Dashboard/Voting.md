# Голосование World

Под выбранным изображением встроены реакции 👍 / 👎 отдельного обсуждения `ALIVE vote v1 <code>`. Общая ветка комментариев персонажа сохраняется отдельно. Запись выполняет Giscus с GitHub OAuth; секретов в сайте нет.

Учитываются только `esannikov` (Женя, вес 1), `ElenaAlive` (Лена, вес 2) и `isto3110-ship-it` (Игорь, вес 1). Реакции других аккаунтов не участвуют в итогах. Giscus допускает одновременно две реакции: в сводке учитывается последняя из активных реакций участника по времени GitHub. Повторное нажатие снимает реакцию. Это правило явно указано у голосования; два голоса одного человека не суммируются.

Существующее задание Update World comments запускает `scripts/sync_world_comments.py` из ветки сайта. Оно теперь также читает реакции и публикует `docs/World/votes.json`. Сводка голосов обновляется два раза в день: после 09:00 и 21:00 по Europe/Kyiv, ближайшим запуском существующего задания. Переход на летнее время учитывается. Задержки GitHub Actions возможны. На странице нет фонового опроса. Для свежего ручного разбора используется --refresh-votes. Имена и взвешенный результат отражают опубликованную сводку; реакция самого пользователя внутри виджета отображается сразу. Поле generatedAt — время построения сохранённой сводки, не обещание непрерывной синхронизации.

## Статусы для агента

- `unvoted`: учитываемых голосов нет.
- `for`: есть голоса за, против нет; это не финальное утверждение.
- `mixed`: мнения расходятся.
- `against_pending`: только один участник против.
- `unanimous_against`: минимум два разных участника против, никто за. Вес Лены не заменяет второго участника.

JSON содержит `votes` с логинами, выбором, весом, временем и ID реакции; `scores` — взвешенные суммы, `people` — количество разных людей, ссылку на обсуждение и статус. `automaticRemoval` всегда false. Скрипт не изменяет реестр изображений.

Перенос в удалённые выполняется только после прямой команды пользователя проанализировать отзывы и голосования. Перед переносом агент должен обновить сводку с GitHub и сопоставить её с текстовыми отзывами. При недоступной или устаревшей сводке, неоднозначном коде или противоречащем более позднем указании пользователя перенос не выполняется. Коды и источник сохраняются; голосование не является поручением стереть Git-историю.
