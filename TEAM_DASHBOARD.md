## Моя копія

Поточну гілку, список змінених файлів та операції Git показує **жива панель плагіна**. Відкрийте командну палітру **Ctrl+P / Cmd+P → Git: Open source control view** й залиште панель праворуч. Для історії локальної копії — **Git: Open history view**.

Ця сторінка — спільна навігація. Локальний стан кожного учасника окремий: назва гілки й зміни в панелі стосуються саме його комп’ютера.

## Почати правку

> [!IMPORTANT]
> **Перед редактурою поставте автоматику на паузу.** Команда **Git: Pause/Resume automatic routines** має показати **Paused automatic routines**. Агент після цього створює робочу гілку.

Скажіть агенту:

> Почнімо правку ALIVE. Перевір мої незбережені зміни, постав автоматичні операції Git на паузу, створи окрему гілку й допоможи відредагувати потрібний розділ.

### Відправити написане однією командою

Перевірте, що агент уже підготував робочу гілку для цієї правки та її відправлення. Після редагування натисніть:

**Відкрийте нотатку → пишіть руками → Ctrl+P / Cmd+P → Git: Commit-and-sync.**

Якщо нотатка відкрита тільки для читання, **Ctrl+E / Cmd+E** перемикає режим редагування. Сам текст Obsidian зберігає автоматично.

Плагін збереже версію й відправить ваші правки в цю гілку. Він включить усі поточні зміни проєкту, які не ігнорує Git. Пауза автоматичних операцій ручній команді не заважає.

**Дочекайтеся успішного push.** Саме натискання кнопки ще не підтверджує передачу. Commit-and-sync не створює PR і не робить зміни спільними: запит на перегляд після цього готує агент або відповідальний редактор. Для роботи через агента достатньо сказати:

> Покажи зміни й підготуй запит на перегляд. Відділи нові факти світу від редактури формулювань. Перевір джерела та посилання.

## Прийняти спільну версію

Відповідальний редактор переглядає pull request, залишає коментарі та приймає погоджені зміни. Після підтвердження MERGED агент перевіряє, що в автора не лишилося невідправленої роботи, повертає його до чистої main й отримує оновлення. Потім відновлюється автоматика командою **Git: Pause/Resume automatic routines**. Перевірте повідомлення **Resumed automatic routines**. Поки копія лишається в робочій гілці з паузою, нові зміни main до неї автоматично не надходять.

> [!WARNING]
> **Помилка отримання, конфлікт або розходження історії:** збережіть роботу й передайте повідомлення агенту. Автоматичні коміти та push вимкнені; налаштування не мають обирати чужий або свій текст замість людини.
