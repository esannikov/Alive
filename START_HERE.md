# Як підключитися до ALIVE

У кожного буде власна папка ALIVE на комп’ютері. Obsidian показує її як вікі; GitHub передає зміни між учасниками. Агент працює з цією самою папкою.

## 1. Отримати доступ

1. Створіть власний безкоштовний акаунт на [GitHub](https://github.com/signup), якщо його ще немає.
2. Передайте адміністратору репозиторію свій **GitHub-логін**. Пароль або токен передавати не потрібно.
3. Адміністратор запросить цей акаунт до приватного [esannikov/Alive](https://github.com/esannikov/Alive) з правом редагування. Прийміть запрошення, увійшовши саме у свій акаунт.
4. Відкрийте посилання на репозиторій. До приймання запрошення GitHub може показувати 404 — це очікувана поведінка приватного доступу.

Стан на початок пілота: доступ конкретному учаснику виникає лише після його запрошення та приймання. Наявність цієї інструкції не означає, що запрошення вже надіслано.

## 2. Підключити без термінала

1. Установіть [Obsidian](https://obsidian.md/download) і [GitHub Desktop](https://desktop.github.com/).
2. У GitHub Desktop увійдіть у свій GitHub-акаунт.
3. Оберіть **File → Clone repository**, знайдіть `esannikov/Alive`, виберіть локальну папку й натисніть **Clone**. Копію тримайте у звичайній локальній папці поза iCloud/OneDrive та іншими сервісами синхронізації.
4. В Obsidian оберіть **Open folder as vault / Відкрити папку як сховище**, потім папку щойно клонованого Alive.
5. Відкрийте `README.md`. Це головна сторінка вікі. Увімкнути сторонні плагіни або купувати Obsidian Sync для цього не потрібно.

Перед читанням оновлень: у GitHub Desktop натисніть **Fetch origin**, потім **Pull origin**, якщо ця кнопка з’явиться. Перед оновленням незавершені правки варто зберегти у своїй гілці; за сумнівів попросіть агента перевірити стан.

## 3. Підключити агента

Відкрийте локальну папку Alive у програмі свого агента або надайте йому доступ до неї. Браузерний чат без доступу до локальних файлів або налаштованого GitHub-конектора сам їх не бачить.

Скопіюйте агенту:

> Працюємо з приватним репозиторієм https://github.com/esannikov/Alive. Допоможи підключити його на моєму комп’ютері. Використовуй мій власний GitHub-акаунт; вхід я виконаю самостійно через браузер. Перевір, чи прийнято запрошення і чи є право редагування. Якщо копія вже існує, спочатку перевір її стан і не перезаписуй незбережені зміни. Після клонування прочитай AGENTS.md і CONTRIBUTING.md. Покажи, яку папку відкрити в Obsidian, та перевір README і сторінку персонажів. Нові правки готуй у гілці через pull request; до творчого погодження основну версію не змінюй.

Агент користується вашою авторизацією. Окремий GitHub-акаунт для агента на цьому етапі не потрібний. Секрети вводьте через штатний вхід; не вставляйте паролі чи токени в чат, Markdown або репозиторій.

## 4. Щоденна робота

Перед початком скажіть агенту: «Перевір мої незбережені зміни й онови ALIVE до останньої базової версії».

Далі можна читати й редагувати тексти в Obsidian. Наприкінці: «Покажи мої зміни, перевір посилання і створи запит на перегляд. У поясненні відділи редактуру формулювань від нових фактів світу».

Людина переглядає пропозицію. Після приймання інші учасники отримують її через оновлення своєї копії. Якщо два учасники змінили один фрагмент, агент показує обидва варіанти й погоджує зміст, а не відкидає одну версію автоматично.

Коментарі до конкретної правки залишайте в pull request. Окреме питання про світ можна створити у вкладці **Issues**. Такі обговорення зберігаються на GitHub; агент читає їх через GitHub-доступ, звичайне оновлення папки не завантажує коментарі.

## Якщо ви поки лише читаєте

Після приймання запрошення можна читати біблію прямо в браузері на GitHub, переходячи з README. Установка Obsidian потрібна для локальної вікі. ZIP дозволяє отримати разовий знімок, але не налаштовує обмін змінами.
